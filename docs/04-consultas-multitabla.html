💸 1. Transacciones con Detalle Completo

Obtiene las transacciones con su categoría, cuenta y usuario
Objetivo: Mostrar todas las transacciones de un usuario con el nombre de su categoría y el nombre de la cuenta asociada. Esto permite ver el detalle completo en un solo listado.
transaccion categoria cuenta usuario 
SELECT 
    u.nombre AS usuario,
    t.fecha,
    t.descripcion,
    c.nombre AS categoria,
    cu.nombre AS cuenta,
    t.tipo,
    t.monto
FROM transaccion t
INNER JOIN usuario u ON t.id_usuario = u.id_usuario
INNER JOIN categoria c ON t.id_categoria = c.id_categoria
LEFT JOIN cuenta cu ON t.id_cuenta = cu.id_cuenta
WHERE t.id_usuario = 100
ORDER BY t.fecha DESC
LIMIT 10;

🏦 2. Saldo Actual por Cuenta

Calcula el saldo real de cada cuenta sumando ingresos y restando gastos, aportes y pagos
Objetivo: Calcular el saldo actual de cada cuenta del usuario considerando su saldo inicial, todas las transacciones, los aportes a metas y los pagos de deudas.
cuenta transaccion aporte_meta pago_deuda 
SELECT 
    cu.nombre AS cuenta,
    cu.tipo,
    cu.saldo_inicial,
    COALESCE(SUM(CASE WHEN t.tipo = 'ingreso' THEN t.monto ELSE -t.monto END), 0) AS movimientos,
    COALESCE((SELECT SUM(monto) FROM aporte_meta 
              WHERE id_cuenta = cu.id_cuenta), 0) AS aportes,
    COALESCE((SELECT SUM(monto) FROM pago_deuda 
              WHERE id_cuenta = cu.id_cuenta), 0) AS pagos,
    cu.saldo_inicial 
        + COALESCE(SUM(CASE WHEN t.tipo = 'ingreso' THEN t.monto ELSE -t.monto END), 0)
        - COALESCE((SELECT SUM(monto) FROM aporte_meta 
                    WHERE id_cuenta = cu.id_cuenta), 0)
        - COALESCE((SELECT SUM(monto) FROM pago_deuda 
                    WHERE id_cuenta = cu.id_cuenta), 0) 
    AS saldo_actual
FROM cuenta cu
LEFT JOIN transaccion t ON t.id_cuenta = cu.id_cuenta
WHERE cu.id_usuario = 100 AND cu.activa = TRUE
GROUP BY cu.id_cuenta, cu.nombre, cu.tipo, cu.saldo_inicial
ORDER BY saldo_actual DESC;

🎯 3. Progreso de Metas con Aportes

Calcula el progreso real de cada meta sumando todos sus aportes
Objetivo: Mostrar el progreso de cada meta del usuario, sumando los aportes individuales y calculando el porcentaje completado.
meta aporte_meta cuenta usuario 
SELECT 
    u.nombre AS usuario,
    m.nombre AS meta,
    m.monto_objetivo,
    m.monto_inicial,
    COALESCE(SUM(a.monto), 0) AS total_aportes,
    m.monto_inicial + COALESCE(SUM(a.monto), 0) AS total_ahorrado,
    ROUND(
        ((m.monto_inicial + COALESCE(SUM(a.monto), 0)) / m.monto_objetivo) * 100, 
        1
    ) AS progreso_porcentaje,
    COUNT(a.id_aporte) AS numero_aportes,
    m.fecha_limite,
    m.estado
FROM meta m
INNER JOIN usuario u ON m.id_usuario = u.id_usuario
LEFT JOIN aporte_meta a ON m.id_meta = a.id_meta
WHERE m.id_usuario = 100
GROUP BY m.id_meta, u.nombre, m.nombre, m.monto_objetivo, 
         m.monto_inicial, m.fecha_limite, m.estado
ORDER BY progreso_porcentaje DESC;

💳 4. Deudas con Historial de Pagos

Muestra cada deuda con su saldo pendiente y el total de pagos realizados
Objetivo: Mostrar todas las deudas del usuario con su saldo pendiente, el total pagado, el número de pagos y el estado actual.
deuda pago_deuda usuario cuenta 
SELECT 
    u.nombre AS usuario,
    d.acreedor,
    d.monto_total,
    d.tasa_interes,
    COALESCE(SUM(p.monto), 0) AS total_pagado,
    d.monto_total - COALESCE(SUM(p.monto), 0) AS saldo_pendiente,
    COUNT(p.id_pago) AS numero_pagos,
    d.fecha_vencimiento,
    d.estado,
    CASE 
        WHEN d.tasa_interes > 28.79 THEN '⚠️ Tasa de usura'
        ELSE '✅ Tasa normal'
    END AS alerta_usura
FROM deuda d
INNER JOIN usuario u ON d.id_usuario = u.id_usuario
LEFT JOIN pago_deuda p ON d.id_deuda = p.id_deuda
WHERE d.id_usuario = 100 AND d.estado != 'pagada'
GROUP BY d.id_deuda, u.nombre, d.acreedor, d.monto_total, 
         d.tasa_interes, d.fecha_vencimiento, d.estado
ORDER BY d.tasa_interes DESC;

📅 5. Presupuesto vs Gasto Real

Compara el límite presupuestado con el gasto real por categoría
Objetivo: Comparar el presupuesto asignado a cada categoría con el gasto real del mes, mostrando el porcentaje de uso y si se excedió el límite.
presupuesto detalle_presupuesto categoria transaccion 
SELECT 
    c.nombre AS categoria,
    dp.limite AS presupuestado,
    COALESCE(SUM(t.monto), 0) AS gastado,
    dp.limite - COALESCE(SUM(t.monto), 0) AS disponible,
    ROUND(
        (COALESCE(SUM(t.monto), 0) / dp.limite) * 100, 
        1
    ) AS porcentaje_usado,
    CASE 
        WHEN COALESCE(SUM(t.monto), 0) >= dp.limite THEN '🚨 EXCEDIDO'
        WHEN COALESCE(SUM(t.monto), 0) >= (dp.limite * 0.8) THEN '⚠️ Alerta 80%'
        ELSE '✅ Normal'
    END AS estado_presupuesto
FROM presupuesto p
INNER JOIN detalle_presupuesto dp ON p.id_presupuesto = dp.id_presupuesto
INNER JOIN categoria c ON dp.id_categoria = c.id_categoria
LEFT JOIN transaccion t ON t.id_categoria = c.id_categoria
    AND t.tipo = 'gasto'
    AND MONTH(t.fecha) = p.mes
    AND YEAR(t.fecha) = p.anio
WHERE p.id_usuario = 100 
    AND p.mes = MONTH(CURDATE())
    AND p.anio = YEAR(CURDATE())
GROUP BY c.nombre, dp.limite
ORDER BY porcentaje_usado DESC;

📊 6. Reporte Consolidado por Categoría

Resumen de ingresos, gastos y balance agrupados por categoría
Objetivo: Generar un reporte consolidado que muestra, para cada categoría del usuario, el total de ingresos, gastos y el balance neto en un rango de fechas.
categoria transaccion usuario cuenta 
SELECT 
    u.nombre AS usuario,
    c.nombre AS categoria,
    c.tipo AS tipo_categoria,
    COUNT(t.id_transaccion) AS numero_transacciones,
    COALESCE(SUM(CASE 
        WHEN t.tipo = 'ingreso' THEN t.monto 
        ELSE 0 
    END), 0) AS total_ingresos,
    COALESCE(SUM(CASE 
        WHEN t.tipo = 'gasto' THEN t.monto 
        ELSE 0 
    END), 0) AS total_gastos,
    COALESCE(SUM(CASE 
        WHEN t.tipo = 'ingreso' THEN t.monto 
        ELSE -t.monto 
    END), 0) AS balance_neto,
    ROUND(AVG(t.monto), 2) AS promedio_por_transaccion
FROM categoria c
INNER JOIN usuario u ON c.id_usuario = u.id_usuario
LEFT JOIN transaccion t ON c.id_categoria = t.id_categoria
    AND t.fecha BETWEEN '2026-01-01' AND '2026-12-31'
WHERE c.id_usuario = 100
GROUP BY u.nombre, c.id_categoria, c.nombre, c.tipo
HAVING numero_transacciones > 0
ORDER BY balance_neto DESC;
