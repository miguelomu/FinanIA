# 💰 FinanIA — Gestor Inteligente Financiero

Sistema web para la gestión de finanzas personales, diseñado para estudiantes universitarios colombianos. Combina registro de transacciones, metas de ahorro, gestión de deudas, presupuestos y reportes visuales, con un enfoque educativo y adaptado al contexto local.

---

## 🎯 Problema que resuelve

Los estudiantes universitarios colombianos no llevan control de sus finanzas porque:
- Registrar gastos es tedioso
- No saben interpretar sus datos financieros
- Las apps existentes están en otras monedas o contextos

FinanIA ataca estos tres puntos con registro simplificado, análisis automático y contexto local (COP, tasas, inflación).

---

## ✨ Funciones actuales (MVP)

- 🔐 Autenticación con 3 roles (Invitado, Registrado, Premium)
- 💸 CRUD completo de transacciones
- 🎯 Metas de ahorro con historial de aportes
- 💳 Deudas con historial de pagos
- 📅 Presupuestos mensuales por categoría
- 🏷️ Categorías personalizables
- 📈 Reportes con gráficas (Chart.js) y exportación a PDF

---

## 🛠️ Stack tecnológico

- **Backend:** PHP 8+ con PDO
- **Base de datos:** MySQL 8
- **Frontend:** HTML5, CSS3, JavaScript
- **Gráficas:** Chart.js
- **Entorno local:** XAMPP (Apache + MySQL)
- **Control de versiones:** Git + GitHub
